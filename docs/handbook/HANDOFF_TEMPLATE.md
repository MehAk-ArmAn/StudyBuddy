# Copy for each teammate handoff

```md
## Change summary
- What was changed and why:
- Commit and branch:
- Files/routes/models affected:

## Permissions / privacy / points
- Roles allowed and denied:
- Data scope / migration / backup:
- Reward or game completion implications (if applicable):

## Verification
- Commands + pass/fail:
- Browser + mobile/device checks:
- What was NOT tested:

## Handoff
- Known issues / blockers:
- How to reproduce:
- Rollback/restore steps:
- Reviewer / next owner (if assigned):
```

Never paste real credentials, learner data, private URLs or SQL rows into handoff notes.
