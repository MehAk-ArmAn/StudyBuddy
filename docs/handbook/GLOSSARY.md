# Glossary

- **Control Room:** authenticated administrative CMS/dashboard.
- **Head Admin:** protected canonical top-level administrator; not a code-execution permission.
- **PCL staff:** delegated operations/content/support team with scoped grants.
- **School OS:** organization application, approved membership, board, Connect and Safety Center.
- **Tenant isolation:** one school cannot read/change another school's data.
- **Reward journal:** transaction history used with spendable `users.cosmic_points` balance.
- **Verified completion:** server-validated game result, not merely a user-supplied timestamp or launch event.
- **Badge unlock:** profile cosmetic/achievement tied to a verified server event.
- **Blade:** Laravel's server-rendered template engine.
- **Source install vs activation:** code installation is separate from locally applying MySQL migrations, with an independent DB backup.
- **Phase pack:** a versioned collection of changes, not automatic proof of a production deployment.
