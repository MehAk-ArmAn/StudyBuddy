# School OS: governance, messaging and safety

**P11B Board** — School task model/controller and school dashboard; organization members with the right role can create/manage tasks. 

**P11C Connect** — School conversation, messages, channels and direct chat; report handling/read receipts and protected attachment download paths. All reads/edits/downloads must be scoped to the current organization and active membership.

**P11D Safety Center** — Manager notices, staff read receipts, confidential concerns, review statuses and organization-bound notice export. This is **in-app functionality**; do not describe it as email/push notification delivery or automated message scanning.

Typical school navigation: workspace → Board → Connect → Safety. At each transition, verify a School Owner and a limited Teacher can see the right links; unauthorized access by URL must still be blocked.

**Privacy:** Avoid copying message bodies or student details into public docs or third-party issue trackers. There is no blanket PCL access to private school DMs. Retention/export policy requires explicit product/legal review.

**Calendar:** Phase 11E meeting requests were proposed, but the supplied latest logs do not prove an 11E install. Treat as planned until validated from the actual checkout.
