## Non-negotiable implementation rules

1. **Real code first:** Browse both official [React Bits](https://reactbits.dev/) / [source](https://github.com/DavidHDev/react-bits) and [ReactDrops](https://reactdrops.dev/components) / [source](https://github.com/crisjavr/reactdrops), select actual components, review licensing, integrate official source when publicly available, and connect to real Laravel/React functionality. No inspiration-only fakery.
2. **No Pro access is assumed.** The user has **no React Bits Pro account/license** as of 18 November. Pro UI blocks in the list below remain *wishlist references* unless licensed source is legally obtained. Build **original** or permissibly licensed open-source functional equivalents instead. Don't copy proprietary Pro code or mislabel alternatives as actual Pro installs.
3. **Preserve the existing W12/Base44-inspired homepage design, active nav/header effects, code, Laravel backend, data, dashboards, team work, real asset rights, auth/privacy/age permissions.** Do not replace working pages just for visual polish.
4. **Site-wide, not dashboard-only:** Public homepage, apps catalogue, roles, schools, onboarding, learning content, profile, admin/control room, AI-style Study Space, mobile navigation and role-adaptive dashboards all need coherent selections. Do not put every effect everywhere.
5. **Responsiveness & accessibility:** Mobile-first, graceful touch and keyboard behavior, reduced-motion support, reasonable bundle cost, no permanent cursor overlays for touch devices, restrained WebGL, usable forms/charts and no fake data or dead UI.
6. **Integration status must be verifiable:** Distinguish `selected`, `previously reported`, `installed in source`, `mounted live`, `tested on device`, `not accessible / Pro`, and `original functional alternative`; one never implies another.
7. **Backend source of truth:** Real authenticated/student-scoped records, actual class assignments and completion events, no invented grades, class statistics, visit-time or AI replies. Parent/school/teacher/admin privileges are server-checked.
